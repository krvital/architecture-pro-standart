##### Сервис расчёта ключевой ставки:

- Будет создан внутри интернет-банка как отдельный модуль, но не отдельный микросервис, чтобы не требовать отдельной команды и инфраструктуры.
- Сервис будет автоматически обновлять ключевую ставку раз в день, основываясь на ставке рефинансирования Центробанка и внутренних правилах банка.
- Данные о ставке будут доступны для всех внутренних процессов, где требуется актуальная ставка по депозитам.

##### Доступ к данным:

- **Для внутреннего использования** данные будут доступны через API-интерфейс внутри интернет-банка.
- **Для партнёрского кол-центра** данные будут публиковаться на FTP-сервере, откуда они могут скачиваться и использоваться в их системе.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

##### Отдельный микросервис для ключевой ставки

**Описание:** Создать полноценный микросервис для расчёта и хранения ключевой ставки, который будет предоставлять API для всех внутренних и внешних потребителей.

**Плюсы:**

- Чёткая изоляция логики расчёта ставки
- Легко масштабировать независимо от интернет-банка
- Возможность развёртывания и обновления без влияния на основной интернет-банк

**Минусы:**

- Нет отдельной команды для поддержки микросервиса
- В текущей инфраструктуре банка нет полноценной поддержки микросервисов
- Требуются дополнительные DevOps-ресурсы для деплоя и мониторинга



##### Расчёт ставки вручную с передачей файлов (как сейчас)

**Описание:** Сотрудники бэк-офиса продолжают считать ставку в Excel и рассылать файлы внутри банка и партнёрскому кол-центру.

**Плюсы:**

- Простота реализации
- Не требуется программная доработка интернет-банка
- Используется существующий процесс и навыки сотрудников

**Минусы:**

- Риск ошибок из-за ручного расчёта
- Нет автоматизации обновления ставок
- Медленный процесс для MVP и дальнейшей цифровизации
