##### Система кредитного скоринга

Выполняет оценку кредитного риска клиентов и формирует предодобренные предложения.

- Ежесуточно ночью выполняет расчёт по всем активным клиентам банка.
- На основе данных из АБС и внутренней кредитной истории формирует предодобренные кредитные предложения (сумма, срок, ставка).
- Передаёт сформированные предложения в Кредитный конвейер
- В рабочее время система обрабатывает только запросы от Кредитного конвейера для индивидуальных скорингов при рассмотрении заявок, не участвует в потоке заявок с сайта.

##### Кредитный конвейер

- Принимает результаты ночного расчёта от системы кредитного скоринга и сохраняет их как предодобренные предложения для клиентов.
- В зависимости от источника заявки:
  - для клиентов интернет-банка использует готовое предодобренное предложение и обрабатывает заявку немедленно;
  - для клиентов сайта вызывает только бюро кредитных историй, не нагружая скоринговую систему.
- После одобрения заявки передает результат в АБС (раз в сутки).
- Отправляет уведомления клиентам через СМС-шлюз.

##### Интернет-банк

- При входе клиента запрашивает предодобренные предложения из кредитного конвейера.
- Позволяет клиенту подать заявку по предодобренному кредиту без ожидания.
- Подтверждает действия клиента через СМС-код.
- Отправляет запросы в кредитный конвейер для получения статусов заявок и передачи подтверждений.



### <a name="_bjrr7veeh80c"></a>**Альтернативы**

##### 1. Обновить АБС и добавить очередь

**Альтернатива:** Когда заявка создаётся в АБС, она сразу публикуется в очередь сообщений, откуда кредитный конвейер может получать данные в реальном времени.

**Плюсы:**

- Почти мгновенная доставка заявок
- Очередь легко масштабируется под нагрузку

**Минусы:**

- АБС реализована на Delphi и Oracle. Скорее всего не будет возможности для интеграции с Kafka или  RabbitMQ
- Требуется новая инфраструктура 

##### 2. Перенести создание заявок по предодобренным кредитам в Кредитный конвейер

Когда клиент подаёт заявку через интернет-банк, она сразу создаётся в кредитном конвейере, а не в АБС. АБС получает уже готовое решение раз в сутки.

**Плюсы:**

- Заявка сразу попадает в обработку.
- Ускоряется реакция сотрудника и клиента.

**Минусы:**

- Нужно продумать схему синхронизации идентификаторов заявок и клиентов между системами.
- Возможна дублирующая логика (если в АБС всё же создаётся копия заявки).
